# Cygnus

## Project

Evaluating the Reliability of Machine Learning Confidence for Variable-Star Classification Across Astronomical Surveys.

## Research Question

Can we trust the confidence score given by an ML model when it classifies variable stars from a different astronomical survey?

## Focus

- Astronomy
- Machine Learning
- Eclipsing binary stars
- NASA TESS
- ESA Gaia DR3

---

## Key Results

| Metric | TESS (in-survey) | Gaia (cross-survey) |
|--------|-----------------|---------------------|
| Accuracy | 92.5% | 32.5% |
| Mean confidence | 94.1% | 86.0% |
| Calibration gap | +0.016 | +0.535 |
| Brier score | 0.060 | 0.488 |
| High-conf accuracy (≥0.90) | 96.6% | 48.5% |

**Answer to the research question:** No. The model's confidence score does not remain reliable cross-survey. When applied to Gaia data, it claims ≥90% confidence while being correct only 48.5% of the time — barely above random.

## Reproducing the Research

> **Note:** The scripts below are reconstructions of the original analysis based on the
> documented methodology in `results/data_preparation_report.md` and
> `results/ml_experiment_report.md`. They were not recovered from git history.
> They are designed to reproduce the same output files and numerical results as the
> original experiment. If any result differs, check whether your Python/scikit-learn
> version affects random number generation.

### Requirements

Python 3.10+ is required. Install dependencies:

```bash
pip install -r requirements.txt
```

### Step 1 — Data preparation

Cleans the raw TESS catalog (removes 21 invalid records) and adds the binary label.

```bash
python experiments/01_data_preparation.py
```

Output: `data/processed/tess_clean.csv` (4,563 rows)

### Step 2 — Feature engineering

Extracts the two cross-survey features from TESS and builds the Gaia feature table.

```bash
python experiments/02_feature_engineering.py
```

Output: `data/processed/tess_features.csv`, `data/processed/gaia_features.csv`

### Step 3 — Train and evaluate

Trains the Random Forest on TESS data, evaluates on the TESS test set, applies to Gaia.

```bash
python ml/train_evaluate.py
```

Output: `results/ml_summary.json`, `results/tess_test_predictions.csv`, `results/gaia_predictions.csv`

### Step 4 — Calibration analysis

Computes Brier scores, calibration gaps, runs the additional experiments, generates the reliability diagram.

```bash
python ml/calibration_analysis.py
```

Output: `results/phase5/` (metrics CSV, prediction CSVs, reliability diagram PNG)

### Run the full pipeline at once

```bash
python experiments/03_cross_survey_experiment.py
```

### Jupyter notebook

An interactive notebook walks through the full analysis with inline plots:

```bash
jupyter notebook notebooks/CYGNUS_analysis.ipynb
```
